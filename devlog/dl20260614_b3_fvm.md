## Key findings

- **Build: shelved/unbuilt.** `src/fvm/CMakeLists.txt` defines an `fvm` library target but no parent
  `add_subdirectory(fvm)` exists; nothing outside src/fvm references it; and `cl_FVM_Factory.cpp:871`
  constructs a 3-arg `Tensor<real> G(...)` that does not match any current `cl_Tensor` constructor (4/5/
  Matrix), so the assembly path would not even compile against the present Tensor API. (Matches B4a.)
- **Intent: MPFA-O (Aavatsmark) for thin-shell thermal conduction** of HTS tapes - 2D MPFA on the
  reference plane with thickness `t` as a flux scaling factor (NOT full 3D volumetric FVM); intended
  payoff is a perfect DOF match with the Maxwell thin-shell for quench (Joule-heating) coupling.
- **Implemented vs stubbed:** geometry + node-local transmissibility math are BUILT - mesh extraction,
  subcells (3/triangle), subedges (master/slave), Gram matrices (3x2), interaction-region Nodes, and the
  node-local A/B/C=inv(A)*B system (conservation-checked per the doc). STUBBED/ABSENT: material lambda*l*t
  scaling (two TODOs at Factory.cpp:940,955), C-matrix storage (SubEdge::mC[4] declared but never
  populated, no setter), global assembly, RHS, BCs, solver integration, 3D extrusion, IWG wrapper, Maxwell
  coupling. The node-local loop currently terminates after the FIRST node via a debug exit(0)
  (Factory.cpp:967). MPFAO.cpp is a 33-line stub (mesh-extract only).
- **Coupling: all intent, nothing wired** - planned via FVMFactory + IWG_FVM_MPFAO + set_thermal_kernel
  (the ThermalFactory/hphiTrun pattern).
- **Tests: NONE** (expected for WIP).
- **Provenance:** Aavatsmark 2002, Klausen & Winther 2006, Ingram 2010, Wheeler 2011 (standard MPFA, with
  DOIs in the theory doc); thin-shell thermal application is the author's contribution.
