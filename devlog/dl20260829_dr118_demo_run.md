# DR-118: the demo run, and why the shipped binary could not provide it

**Date:** 2026-08-29
**Purpose:** record the conducted demo run that discharged DR-118's last gate, and the
strikes of DR-121, DR-123
**Module:** executables, circuit

## The stale-binary trap

DR-118's gate was "one demo run — the executable loop itself is review-only until run".
The obvious way to serve it is to run `cmake-build-debug/bin/electricalCircuit`. That would
have been wrong and would have looked right.

That binary is dated 2026-08-28 00:01. `src/executables/electricalCircuit.cpp` carrying the
DR-118 fix is dated 2026-08-29 01:49, and `cl_ElectricalCircuit.cpp` carrying the DR-138 and
DR-139 fixes is dated 2026-08-29 04:40. `make check` builds the test targets and the library,
not the solver executables, so a green suite does not refresh this binary. Running it would
have exercised the old loop and reported a pass.

The run was therefore done against a binary linked in the session sandbox from the same
`libbelfem.a` that `make check` had just produced (20:32). A one-line env-gated forced
rejection was injected into a *scratchpad copy* of the source; `git status` confirms
`src/executables/electricalCircuit.cpp` is untouched.

## Why a plain run is not the gate

The first run completed 412 steps, exit 0, every step converging in two Newton iterations —
and exercised none of what DR-118 changed. The fix is entirely about the rejected-timestep
path, so a run without a rejection is not evidence about it. Three forced cases followed.

| case | what it proves | result |
|---|---|---|
| baseline | record semantics | 413 rows = pre-loop `t=0` row + one per accepted step; times strictly increasing; dt grows exactly 1.5x to the 200 us cap; clean exit, no double free |
| A: reject first step | the OLD code turned this into a hard `ShiftRegister::revert` abort (`shift_back` with no prior `shift`) | completes, exit 0, retry re-solves from `t=0` at halved dt |
| B: reject step 201 | time must not advance on a failed step, and the failed iterate must not be recorded | attempt at `37.782 -> 37.982 ms` rejected; retry restarts from the SAME `37.782 ms` at dt/2; 412 accepted steps -> 413 rows, identical to baseline, so no row for the rejected attempt |
| C: unbounded rejection | the new dt floor replaced an infinite halving spin | 28 halvings, then `Timestep collapsed to 1e-12 s or below without convergence`, clean abort |

Physics cross-check on case B: sampled at the 200 baseline points lying inside both grids,
the trajectory tracks the never-rejected baseline to <= 9.2e-4 relative on all five channels.

### One measurement artifact worth recording

The first cut of that comparison reported ~4.7e-2 relative and looked like a real
discrepancy. It was not. The two runs end 150 us apart, and the interpolator clamped to the
last sample past the shorter run's end. A unit 50 Hz sine moves at 314 V/s, and
`314 * 150e-6 = 0.047` — the number reproduced the artifact exactly. Restricting the
comparison to the strictly overlapping range gives the 9.2e-4 above. The lesson is the
ordinary one: when a deviation matches a grid offset times a slew rate, suspect the
comparison before the code.

## Strikes
