# BELFEM 0.9.1: Ubuntu portability release

**Date:** 2026-09-13
**Purpose:** Record how 0.9.1 was cut from the `ubuntu_patch` branch and what ships in it.
**Module:** release packaging (`CMakeLists.txt`, `CITATION.cff`, new `CHANGELOG.md`)

## What happened

`ubuntu_patch` was pushed to GitHub only (two commits on top of `f81dd843`: 9ac2505f,
e63f1dfb; see `dl20260913_ubuntu_format_security.md` and `dl20260913_ybco_test_int_abs.md`).
It fast-forwarded cleanly onto `main`. The merge went into GitLab `codes/belfem` (the source
of truth), `devel` was fast-forwarded to the same commit, and the nightly mirror pushes `main`
to GitHub. After that, the `ubuntu_patch` branch was deleted on GitHub.

Release commit on top: version 0.9.0 -> 0.9.1 in `CMakeLists.txt` and `CITATION.cff`
(`date-released` 2026-09-13), and a new top-level `CHANGELOG.md` (Keep a Changelog format,
with 0.9.0 recorded as the first public release). The changelog got a Codex language sweep
(gpt-5.5, read-only). It found no false claims; five overstatements were softened, most
importantly "results are now correct", which the evidence does not support for sites other
than YBCO.

## Gate

The four-way GitLab CI matrix (DEBUG/RELEASE x ARMADILLO/BLAZE, `make check`) ran on the
release commit before tagging `v0.9.1`. It is the first executable gate for the eleven
`std::abs` sites on Rocky. Earlier checks were syntax checks, plus Christian's Ubuntu build.
